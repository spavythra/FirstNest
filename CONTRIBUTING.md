# Contributing to FirstNest Finland

Thank you for your interest in improving FirstNest Finland.

## Development Principles

- Keep the product inclusive for both immigrants and Finnish citizens.
- Prioritize readability, accessibility, and user trust.
- Prefer small, focused pull requests with clear intent.

## Local Workflow

1. Fork and clone the repository.
2. Create a branch with a clear scope:
   - `feat/<short-topic>`
   - `fix/<short-topic>`
   - `docs/<short-topic>`
3. Make changes with meaningful commit messages.
4. Validate manually in desktop and mobile viewport.
5. Open a pull request with context and screenshots.

## Pull Request Checklist

- [ ] Changes are scoped and easy to review
- [ ] UI works on mobile and desktop
- [ ] Existing functionality is preserved
- [ ] Documentation is updated where needed
- [ ] Commit messages explain why, not only what

## Commit Message Convention

Use conventional-style prefixes when possible:

- `feat:` for new user-facing functionality
- `fix:` for bug fixes
- `docs:` for documentation updates
- `chore:` for repo/tooling housekeeping
- `style:` for visual or non-functional presentation changes

Example:

`feat(calculator): improve affordability guidance for low-cushion scenarios`
